# Virtual Chemistry Lab

A browser-based virtual chemistry lab built for a first-year B.Tech chemistry activity.

## Experiments

- Acid-base titration (HCl against NaOH with phenolphthalein, live pH curve)
- Flame test (seven metals plus a mystery sample)
- Indicators and pH (nine solutions, four indicators)

Each experiment can be downloaded as a PDF lab report with the student's details and college logo.

## Run it

Open `index.html` in any modern browser. No install or build step is needed.
